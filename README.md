# Posture Guard

Posture Guard は、猫背になりがちなエンジニアの作業を、姿勢が崩れた瞬間に Wi-Fi 断で強制中断させるネタ寄りのデスクトップアプリです。

長時間の実装中は、気づくと背中が丸まり、首が前に出て、そのまま体を壊しがちです。このアプリは「姿勢が悪いと作業が止まって痛い」という体験を PC 側から叩き込みます。最初に「自分にとっての良い姿勢」を Web カメラで登録し、その姿勢から一定時間ずれると警告を出し、必要に応じて Wi-Fi をオフにします。姿勢が戻らない場合は、画面ロックや再起動も選べます。

## どんなアプリか

- 長時間の PC 作業で猫背になりがちなエンジニア向けの姿勢矯正ネタツールです。
- 一般的な「正しい姿勢」を押し付けるのではなく、最初に登録した自分の基準姿勢からのずれを見ます。
- 姿勢が崩れてもすぐには止めず、警告と猶予時間を挟んでから Wi-Fi をオフにして作業を中断させます。
- 体に悪い姿勢を続けると開発体験も悪くなる、という雑なフィードバックで姿勢を矯正します。
- Wi-Fi を戻す操作は自動化せず、ユーザーが手動で復帰します。
- macOS と Windows で動きます。

## 使うと何が起きるか

1. アプリを起動します。
2. 良い姿勢で座り、`c` を押して基準姿勢を登録します。
3. アプリが Web カメラで姿勢を監視します。
4. 猫背などで姿勢が崩れると、画面に警告とカウントが出ます。
5. 設定した秒数を超えて姿勢が戻らない場合、Wi-Fi がオフになります。
6. さらに姿勢が戻らない場合、設定に応じて画面ロック、再起動、または何もしない動作を実行します。
7. 作業を止められた痛みを受け止めて姿勢を直します。
8. Wi-Fi を自分でオンに戻すと、監視が再開します。

## 画面でできること

起動すると、カメラ画面と設定ウィンドウが開きます。設定ウィンドウでは次の項目を変更できます。

- 基準姿勢を登録する秒数
- 姿勢が崩れてから Wi-Fi をオフにするまでの秒数
- Wi-Fi をオフにするかどうか
- 猶予時間後の動作。画面ロック、再起動、何もしない、から選択
- 警告ポップアップを表示するかどうか

キー操作:

- `c`: 基準姿勢を登録、または登録し直す
- `q`: 終了

## 対応環境

- macOS
- Windows
- Python 3.11 または 3.12

MediaPipe が新しい Python バージョン向けの wheel を提供していない場合があるため、Python は 3.11 または 3.12 を使ってください。

## セットアップ

```sh
uv sync
```

## 実行方法

まずは dry run で動作を確認してください。dry run では Wi-Fi の変更、画面ロック、再起動は実行されず、実行予定のコマンドだけが表示されます。

```sh
uv run posture-guard --dry-run
```

実際に Wi-Fi 制御を有効にして起動する場合:

```sh
uv run posture-guard
```

## Windows での注意

Windows では Wi-Fi アダプターの有効化/無効化に PowerShell の `Get-NetAdapter`、`Disable-NetAdapter`、`Enable-NetAdapter` を使います。Wi-Fi を実際にオフにするには、管理者権限でターミナルを起動してください。

自動検出がうまくいかない場合は、アダプター名を指定します。

```sh
uv run posture-guard --wifi-device "Wi-Fi"
```

## macOS での注意

macOS では Wi-Fi 制御に `networksetup` を使います。自動検出がうまくいかない場合は、デバイス名を指定します。

```sh
uv run posture-guard --wifi-device en0
```

画面ロックはディスプレイスリープ、ユーザーセッションのサスペンド、スクリーンセーバー起動、キーボードショートカットを順に試します。macOS 側で「スリープまたはスクリーンセーバ開始後にパスワードを要求」が有効になっていることを確認してください。

## 姿勢判定について

画面の `score / threshold` は、現在の姿勢が登録した基準姿勢からどれだけ離れているかを示します。スコアは肩の位置、肩に対する頭の位置、肩の傾きを使って計算します。

小さなカメラ位置のずれで過剰反応しないように、肩の位置は頭の位置より軽く扱います。また、`3.01 / 3.00` のようなわずかな超過では Wi-Fi オフのカウントを始めません。デフォルトでは、スコアがしきい値より 15% 高くなった時点からカウントを開始します。この値はカメラ画面に `Off starts at` として表示されます。

## トラブルシューティング

キャリブレーションに失敗する場合は、基準姿勢を登録する秒数を長めに設定し、顔と両肩がカメラに入るようにしてください。1 秒などの短い設定では、必要なサンプル数が集まらないことがあります。

カメラが開けない場合は、OS のカメラ権限を確認し、必要に応じて `--camera` で別のカメラインデックスを指定してください。

```sh
uv run posture-guard --camera 1
```
